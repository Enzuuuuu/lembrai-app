## GitHub MCP

You have access to the GitHub MCP server, which provides tools to interact with the GitHub API. Use it to:

- **Repository operations**: create repos, manage issues, pull requests, branches, and labels
- **Code review**: create and review PRs, comment on code
- **Project management**: manage issues, milestones, and project boards
- **Search**: search code, repositories, issues, and users
- **Content management**: read/write files, manage branches, create commits

When the user asks about GitHub tasks, prefer using the `github` MCP tools over `gh` CLI commands.

The GITHUB_TOKEN is automatically loaded from the environment variable.
